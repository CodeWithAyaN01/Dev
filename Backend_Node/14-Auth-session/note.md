# For this We will install pnpm
```
npm i -g pnpm@latest
```

# After installing
```
pnpm init
pnpm i @types/node @types/express -D
pnpm i express 
```

# Drizzle With pnpm
```
pnpm add drizzle-orm pg dotenv
pnpm add -D drizzle-kit tsx @types/pg
```
